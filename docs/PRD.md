---

## 1. 背景与问题

小红书等平台流行「测一测」（如「你最像哪个历史人物」）类测验。完整商业形态将是多租户 + 兑换码防复用的测验平台，但需要先验证「题好不好玩、结果愿不愿分享」。

因此 **MVP 只做可访问的裸链接测验**：打开即答，不设门禁。兑换码、租户后台、超管额度等全部后置。

---

## 2. 目标与非目标

### 2.1 MVP 目标

1. 用户打开公开链接即可开始答题。
2. 按固定「测试题集」完成作答并看到结果。
3. 结果页可分享/导出（至少一种：长图或分享图）。

### 2.2 MVP 明确不做

- 兑换码 / 输码 / 核销 / 防转卖
- 登录（C 端、租户、超管均不做）
- 多租户、后台、套餐、额度
- 站内支付
- 题库可视化配置后台（题集以代码/静态配置固化）
- 品牌白标、权限、审核、数据大盘

---

## 3. 长期商业模式（非 MVP）

后续才落地，此处仅作方向锚定：

| 线 | 卖什么 | 履约方向 |
| --- | --- | --- |
| ToC | 一次测试资格 | 站外/站内售卖兑换码；出结果核销 |
| ToB | 后台使用权 | 时间 + 码数上限；租户发电给自己的 C 端 |

防复用原则（后期）：商品是码，链接是门脸；公开链可传播，无有效码不能完成测验。

---

## 4. MVP 范围

### 4.1 产品一句话

**一条裸链接 + 一套固定测试题集（题、选项、结果映射）；打开即测，测完出结果。**

### 4.2 测试题集（固化）

以代码或静态配置提供唯一一套内容：

- 题目列表
- 选项及计分/标签规则
- 结果映射表（得分区间或标签组合 → 结果文案/形象）

MVP 无后台改题能力；改题 = 改配置并发版。

### 4.3 功能清单

| 功能 | 说明 |
| --- | --- |
| 落地/开始页 | 裸链接打开；简介 + 开始测试 |
| 答题页 | 按题集作答 |
| 结果页 | 展示映射结果 |
| 导出/分享 | 结果长图或分享图（至少一种） |

无输码页、无后台页、无错误码态（码相关）。

### 4.4 页面与路由建议

| 路径建议 | 页面 |
| --- | --- |
| `/` 或 `/q/:slug` | 开始 / 答题入口 |
| `/result` 或同页状态切换 | 结果展示 |

### 4.5 MVP 用户流程

```text
用户打开裸链接
  -> 开始测试
  -> 按题集答题
  -> 出结果
  -> 导出/分享结果图
```

任意人拿到链接均可重复使用；MVP **不解决**防转卖，只验证内容与体验。

---

## 5. 后期规划（Post-MVP）

### 5.1 第二期：门禁与后台（原讨论的「码 + 超管/租户」）

- 公开链 + 兑换码；**出结果时核销**
- 码状态：未用 → 占用中 → 已用；占用超时策略
- 超管登录：创建/启停租户，设置到期时间 + 码数上限
- 租户登录：生成/作废码、看剩余额度与核销记录
- 租户站外付费；超管手工改额度
- 功能权限仍写死，不做可配置 ACL

### 5.2 第三期：可运营性

- 租户可配置题目 / 选项 / 结果映射
- 多活动、短链、独立开关
- 导出增强（PDF 等）
- 码批量导出、基础数据看板

### 5.3 第四期：商业化加深

- 站内支付（ToC 购码、ToB 购套餐）
- 套餐产品化；可配置功能开关；子账号
- 支付成功自动发码

### 5.4 第五期：增长与风控

- 品牌白标、内容审核、撞码/频率风控
- 可选 C 端登录保存报告
- 开放 API

### 5.5 与 MVP 的扩展关系

MVP 先把 **题集结构 + 答题/出分/结果展示** 跑通。  
二期在入口前加「输码占用」，在出结果时加「核销」，并补租户/超管；题集模型尽量不变，避免推倒重来。

---

## 6. 验收标准（MVP）

1. 通过公开裸链接可直接开始测验，无需登录、无需兑换码。
2. 答完题后能稳定展示与题集映射一致的结果。
3. 结果页支持至少一种导出或保存分享图。
4. 题集内容来自唯一固定配置；无后台配置入口。
5. 不存在兑换码、租户、超管相关页面或接口。

---

## 7. 开放问题 / 实现时再定

| 问题 | 备注 |
| --- | --- |
| 题集题材与文案 | 第一套具体测什么（如历史人物）需定稿 |
| 结果图导出技术方案 | 前端截图或服务端出图 |
| 是否需要开始页文案/封面 | 体验向，不影响门禁 |
| 仓库/对外品牌名 | 仓库暂为 `codequiz-`，品牌名可后定 |
| 二期占用超时回退策略 | 回「未用」或「作废」；倾向回「未用」 |
